# hm2170 registers

This file is everything this driver names or writes. A row with no note is a mode-table value. The driver does not document a bit field for that address.

## What the driver records

Himax HM2170 CSI-2 sensor driver for Raspberry Pi.
Register tables from the Intel IPU6 driver (1928x1088, 2 lanes, GRBG).
Those tables were taken at 19.2 MHz. This module's crystal is 27 MHz, so
link_mhz defaults to 540 (384 * 27/19.2). Silicon revision picks the table:
the third chip-id byte below 4 is rev B, otherwise rev D.

## Named registers

| Name | Address |
| --- | --- |
| `HM2170_REG_CHIP_ID` | `0x0000` |
| `HM2170_REG_MODE` | `0x0100` |
| `HM2170_REG_DELAY` | `0xffff` |

A table entry whose address is `0xffff` is a delay in milliseconds, not a register write.
