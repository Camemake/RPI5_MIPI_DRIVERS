# ov5640 registers

This file is everything this driver names or writes. A row with no note is a mode-table value. The driver does not document a bit field for that address.

## Power-down pin

Connector pin 6 is PWDN and lands on GPIO 34. PWDN is active high, and the chip's internal pull-up holds it in shutdown, so every I2C address NACKs while the pin is high. GPIO 34 is also `cam0_reg`. This driver disables that regulator and holds the pin low. RESETB is pulled up on the module and is not on the connector, so the driver does not pulse PWDN high. GPIO 35 is open on this module.

The module answers at I2C `0x3c`. Chip id `0x300a` is `0x5640`. The crystal is 24 MHz. The mode that streamed is 640×480 UYVY, 2 lanes, link 192 MHz. The receiver logged `Using a link rate of 384 Mbps`.
